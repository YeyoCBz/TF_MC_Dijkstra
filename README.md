# Algoritmo de Dijkstra

Una aplicación web que hace uso del algoritmo de Dijkstra para encontrar el camino mínimo en grafos dirigidos.

## Guía de Uso

### 1. Configuración del Grafo

- Selecciona el número de nodos (8-16) usando el slider
- Elige el tipo de creación:
  - **Aleatorio**: Genera un grafo automáticamente
  - **Manual**: Permite definir conexiones manualmente

### 2. Definición de Nodos

- Selecciona el nodo origen (verde)
- Selecciona el nodo destino (rojo)

### 3. Ejecución del Algoritmo

- Haz clic en "Ejecutar Dijkstra" para calcular el camino mínimo
- Visualiza los resultados y el grafo generado
